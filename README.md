This project corresponds to M2S2 – Personal Portfolio and Pets Website and was developed using HTML5 and CSS3 to create a professional, visually appealing, and easy-to-navigate personal website. The application consists of two interconnected pages: a personal portfolio page and a pets page. The portfolio page introduces Luis Manotas as a Junior Web Developer, presenting personal information, professional goals, work experience, featured projects, and social media links through a modern layout that includes a navigation bar, hero section, experience timeline, project showcase, and footer. The projects section highlights web development work and the technologies used, while the experience section demonstrates professional skills and technical knowledge. The pets page complements the portfolio by showcasing personal interests through a collection of pet profiles, each displayed using individual cards that contain images, names, and descriptions. The website uses semantic HTML elements such as header, nav, main, section, and footer to ensure a well-structured and accessible design, while external CSS provides consistent styling, responsive layouts, and an enhanced user experience. Font Awesome icons are integrated to improve visual presentation and provide quick access to social media platforms. This project reinforces fundamental front-end development concepts, including semantic web structure, multi-page navigation, image integration, responsive design, reusable components, user interface organization, and personal branding, resulting in a complete portfolio website that effectively combines professional information with personal interests.
